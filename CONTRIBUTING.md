# Contributing

Start with [AGENTS.md](AGENTS.md), the single source of maintenance rules and test commands.
Use the [protocol draft](spec/v0.1.md) for wire behavior and [verification record](docs/verification.md)
for the current evidence boundary. Read [SECURITY.md](SECURITY.md) before reporting a security problem.

A useful change contains a focused implementation, an observable failure case, a test of the relevant
public interface, and updated protocol/schema/example documentation when behavior changes. State
which tests actually ran. An unexecuted workflow, a screenshot, or a successful compile is not proof
of the authorization flow. Do not fabricate a benchmark or compatibility claim to fill a badge.

The integration prompt is maintained in [prompts/integrate.md](prompts/integrate.md); the README region
is generated by [scripts/sync_prompt.py](scripts/sync_prompt.py). Skills contain task procedures, not
a duplicated set of repository maintenance rules. Source artifacts use the [MIT license](LICENSE).
